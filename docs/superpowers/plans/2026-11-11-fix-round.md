## Rulings (user, 2026-11-11)
- X while a job or export runs → the window goes away WITHOUT a question, the program goes on by the clock; the first time in a launch a balloon shows. X with nothing running → the program ends. Tray `יציאה` → ends at once, no question.
- While work runs the PC must not sleep; the screen still turns off as usual. When no work runs the PC sleeps per the user's own settings. Allowed: a TEMPORARY "sleep after" = never (AC and DC) while work runs, restored when work ends, at the next launch after a crash, and on uninstall. The "turn off display" setting is never touched.
- Icons: exe, desktop shortcut, Start menu, Add/Remove Programs = the BACKUP logo (`TGBackup.ico`, unchanged). The window's own icons (taskbar button, title bar, Alt+Tab), also when pinned, and the tray = the white cloud.
- Job card lines, in order: (1) phase, with `מעתיק הודעה ` / `מעלה הודעה ` shown as `מעתיק הודעה ביעד ` / `מעלה הודעה ביעד ` (link to the last message in the target, as today); (2) `הודעה אחרונה שטופלה מהמקור: <id>` (link source); (3) `הועתקו: <n>`; (4) `אוחז במקור ב-id <X> מתוך <Y>` — X links the source message, Y links the source's latest message; (5) `⏱ רץ: …`.

## Review Focus
1. The program crashes or the PC loses power while "sleep after" is overridden → the next launch restores the saved values before anything else, and an uninstall restores them too.
2. A network blip in the middle of a long takeout copy → the connect cap ends that run with an error, the job restarts after 15 s (JobManager) and continues from its position; never stuck.
3. A takeout job and the export screen log the same account in at once → one login at a time, one password dialog, the second caller finds the session ready.
4. X during an export with no job → treated as work: hidden, not ended.
5. Phase texts other than copying/uploading (`מאתר ערוצים`, waits, errors) are shown unchanged.
